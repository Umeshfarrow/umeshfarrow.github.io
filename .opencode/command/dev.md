---
description: Start the Vite dev server (host: true, file watching via polling).
---

Start the local development server with:

```
npm run dev
```

The server runs with `host: true` and polling-based file watching (see
`vite.config.js`). Point the user to the printed localhost URL.

If the previous `dist/` output exists and the user wants to preview the
production bundle instead, use `npm run preview` instead.
